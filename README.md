# Digital Marketing SA

A modern and responsive e-commerce website developed for Digital Marketing SA. The platform allows customers to browse products, manage their shopping cart, place orders, and contact the business, while administrators can manage products, users, orders, and customer enquiries through an admin dashboard.

---

## Features

- Responsive website design
- User registration and login
- Product catalogue
- Shopping cart
- Order management
- Contact form
- Admin dashboard
- AI assistant integration
- Product management
- Customer management

## Installation

1. Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/digitalMarketingSA.git
```

2. Import the database.

- Open **phpMyAdmin**
- Create a new database.
- Import:

```
db_setup.sql
```

3. Configure the database connection.

Update the database credentials inside:

```
db_connect.php
```

4. Run the project.

Place the project inside your web server directory (e.g., XAMPP `htdocs`) and start **Apache** and **MySQL**.
